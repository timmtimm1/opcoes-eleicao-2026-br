# Capítulo 1: Introdução

## Core Idea
O livro fornece a base matemática para avaliar opções, estimar probabilidade de sucesso das operações e entender as gregas — para quem só conhece juros compostos. Não é um guia de dicas de investimento; é a "ciência" por trás do prêmio.

## Frameworks Introduced
- **As três afirmações repetidas o livro inteiro**:
  1. **O mercado tem a última palavra.** Avaliar opção é exercício teórico para entender por que ela está sendo negociada a tal preço; o lucro da operação depende inteiramente do preço de mercado. Só cabe decidir entre "dançar ou ficar de fora".
  2. **Avaliar opção é complexo — precisa de computador.** Não dá para encarar com uma HP-12C; use planilha, calculadora web ou programa. É preciso agilidade para acompanhar o mercado.
  3. **O mercado de opções é soma zero** (levemente negativo por causa da corretagem). Para alguém ganhar, outro perde. Opções não pagam dividendos — daí a soma zero. Quem ganha com opção tem sorte.

## Key Concepts
- **Soma zero**: jogo em que a soma dos ganhos e perdas é sempre zero (damas, xadrez), oposto de futebol.
- **Opção como instrumento auxiliar**: mesmo quem não investiria em opção pode usá-la para controle de risco; a teoria vale para "opções reais" (empresas em dificuldade, concessões de jazidas).

## Mental Models
- Pense em avaliação de opção como "tentar entender o preço", não "descobrir o preço certo para arbitrar contra o mercado".
- "No fundo, tudo são opções" — ações de empresas quebradas, imóveis, jazidas: ativos cujo valor vem de eventos futuros incertos.

## Anti-patterns
- **Descobrir a bolsa e logo especular com opção a seco**: forma clássica de perder dinheiro (o autor perdeu tudo em PETRA50 em 2006).
- **Ficar assistindo o home broker o dia todo**: ganhos consistentes só vieram quando o autor se disciplinou a 1–2 operações por mês.

## Key Takeaways
1. O pré-requisito do leitor é apenas juros compostos.
2. O capítulo 6 (volatilidade e preço futuro) é o mais importante para o investidor em opções.
3. Não existe dinheiro fácil no mercado de opções.
4. Para dicas práticas, o autor recomenda Bastter (*Investindo em Opções*, tropicalizado para a BOVESPA) e Lee Lowell (*Get Rich with Options*).
